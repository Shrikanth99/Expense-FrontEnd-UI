# 💰 Expense Tracker App

A full-stack **Expense Tracker Application** built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js), enabling users to manage and analyze their expenses with real-time dashboards and category-wise insights.

---

## 🚀 Features

✅ User authentication (JWT)  
✅ Add, update, delete expenses  
✅ Real-time dashboard with analytics & charts  
✅ Category-wise expense breakdown  
✅ Filter expenses by date, category, or amount  
✅ Responsive design with **React Bootstrap**  
✅ Backend APIs secured with JWT & Bcrypt  

---

## 🛠️ Tech Stack

| Frontend | Backend | Database |
|----------|---------|----------|
| React.js  | Node.js + Express.js | MongoDB |

Other Libraries: Redux, Context API, React Bootstrap, Material UI, Chart.js, Axios, JWT, Bcrypt.js
